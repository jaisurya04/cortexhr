# Data and model provenance

| Item | Source | Notes |
|---|---|---|
| Headcount history, events, sample forecast, attrition, salary, resumes, jobs | `phase3/03_Data/csv/*.csv` (identical copies exist in phase1/phase2) | Synthetic; read-only; checked on load (`forecasting/data.py`) |
| Attrition v2, resume ranker v2, pay-band v1 | `phase3/artifacts/models/*.joblib` + `artifacts/metadata/*.json` | Read-only; attrition also compared with `phase3/reports/task14/attrition_risk_2026.csv` |
| Payroll, attendance, chatbot models | `phase2/models/*.joblib` | SHA-256 verified against `phase2/models/model_registry.json` at start-up |
| Evaluation tables | `phase3/reports/task11..15`, `phase2/reports/...` | Quoted by `scripts/build_docs.py`, never retyped |
| Forecast and monitoring outputs | `phase4/outputs/` | Regenerated by `run_forecast.py` and `monitor.py`; forecast run records SHA-256 of its inputs |
| Restricted vault (CX-12 / CX-15) | not in the repository | Optional local folder via `CORTEXHR_VAULT_DIR` |
| Logo / illustrations | cropped from the approved reference screenshot | see README |
